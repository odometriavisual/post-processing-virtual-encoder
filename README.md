# Instalação

Primeiro instale os pacotes python do pypi:

```bash
pip install -r requirements.txt
  
```

Depois clone o repositório da biblioteca  `visual-odometer`:
```bash
git clone https://github.com/odometriavisual/visual-odometer/
git checkout dev
```

E instale o pacote python dele. Recomenda-se utilizar a flag -e
```bash
pip install -e ${PASTA DO visual-odometer}
```
